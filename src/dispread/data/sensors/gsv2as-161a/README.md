# GSV-2AS mit Displaytech 161A

Dieses Paket beschreibt den Messverstärker von ME-Meßsysteme mit seinem
einzeiligen HD44780-Display. Der geprüfte Aufbau zeigt die Einheit mV/V.

`sensor.json` enthält Gerätekennung, Freigabehinweis und Vorlagenprüfsumme.
`display.json` ordnet den 16 Zeichenpositionen ihre Rollen zu und beschreibt
das Abtastraster sowie die Formatregel für den Zahlenblock.

Die Zeichenvorlagen in `templates.json` stammen aus der eingefrorenen
Stufe 2c vom 2026-09-30. Aufbau, Prüfumfang und Ergebnisse der Abnahme
stehen in [docs/VALIDATION.md](../../../../../docs/VALIDATION.md).
