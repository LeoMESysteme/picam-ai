# Anzeige finden (`detect/`)

Lokalisierungsbausteine für bestätigte und vorgeschlagene Anzeigegeometrie.
Im aktiven Live-Pfad verwendet `TrackedQuadLocator` das vom Menschen
bestätigte Viereck und führt es gegen das Bestätigungsbild nach
([Geometrie](geometrie.md "ECC-Nachführung der bestätigten Anzeige")).
Ein Fundkandidat allein ist keine Bedienerbestätigung.

::: dispread.detect
